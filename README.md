# ГРЕЙТ ТАЙ СПА — редизайн сайта massage58.ru

Статический прототип нового дизайна сайта сети центров тайского SPA в Пензе.
Структура разделов и весь контент (тексты, прайс, акции, мастера, фото) взяты
с текущего сайта massage58.ru, изменён только дизайн и вёрстка.

## Как посмотреть

Любой файл `*.html` открывается прямо в браузере двойным кликом — сборка не нужна.
Для локального сервера (чтобы работала карта и шрифты без ограничений):

```bash
perl tools/serve.pl 8585
```

и открыть http://127.0.0.1:8585/

## Страницы

| Файл | Раздел |
|------|--------|
| `index.html` | Главная: hero, акции, о нас, прайс (по 6 программ в разделе), галерея, контакты |
| `price.html` | Полный прайс по разделам |
| `masters.html` | Мастера |
| `about.html` | О нас + договор-оферта |
| `certificates.html` | Подарочные сертификаты, правила сертификатов и абонементов |
| `contacts.html` | Контакты, карта |
| `articles.html` | Статьи (ссылки ведут на текущий сайт) |
| `franchise.html` | Франшиза + форма связи |
| `personal.html` | Согласие на обработку персональных данных |

## Как менять контент

Страницы генерируются скриптом `tools/build.pl` из данных в папке `data/`:

- `data/price.json` — прайс (разделы и программы: название, цена, описание, фото);
- `data/promos.json` — акции на главной;
- `data/masters.json` — мастера;
- `data/gallery.json` — фото галереи по вкладкам;
- `data/articles.json` — список статей;
- `data/pages/*.html` — длинные тексты (о нас, оферта, сертификаты, франшиза, политика).

Телефоны, адреса салонов, ссылки на соцсети и онлайн-запись задаются в начале `tools/build.pl`.

После правок нужно пересобрать страницы:

```bash
perl tools/build.pl
```

Если менять только оформление, достаточно редактировать `assets/css/style.css`
и `assets/js/main.js` — они подключаются ко всем страницам напрямую.

## Что не подключено

- **Форма записи** (кнопка «Записаться») и форма на странице франшизы показывают
  экран «Заявка принята», но никуда не отправляются. Место для подключения
  обработчика отмечено комментарием в `assets/js/main.js`.
- **Выбор филиала** в шапке запоминается в браузере и скрывает в прайсе программы
  других филиалов (как на текущем сайте), но не влияет на форму на сервере.
- Онлайн-чат с консультантом с текущего сайта не переносился.

## Структура

```
assets/css/style.css   — все стили (цвета и шрифты в :root)
assets/js/main.js      — меню, табы, галерея, модалка записи, фильтр филиала
assets/img/            — изображения с текущего сайта (ужаты до 1600px)
data/                  — контент
tools/build.pl         — генератор страниц
tools/serve.pl         — локальный сервер для просмотра
```
